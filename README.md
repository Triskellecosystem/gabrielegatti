# Gabriele Gatti · Landing Page

Landing page professionale per **Gabriele Gatti**, Osteopata D.O. M.Ost RQ — Studio Polifisio, Meda (MB).

## 🚀 Deploy rapido su Vercel

### Metodo 1 — Vercel CLI
```bash
npm i -g vercel
vercel
```

### Metodo 2 — Vercel Dashboard
1. Vai su [vercel.com/new](https://vercel.com/new)
2. Importa questo repository GitHub
3. Clicca **Deploy** — nessuna configurazione necessaria

## 📁 Struttura progetto

```
gabriele-gatti-landing/
├── index.html       ← La landing page completa
├── vercel.json      ← Configurazione Vercel
```
